# Lekhyo (লেখ্য)

**The Premium, Cross-Platform Bengali Fixed-Layout Input Method Editor (IME).**

Lekhyo is a professional-grade, high-performance Bengali typing software engineered from the ground up for **Windows, macOS, and Linux**. Designed specifically for modern office professionals, publication industries, legal fields, and power users who require absolute layout accuracy and lightning-fast text input.

---

### 🚀 Key Features
* **True Cross-Platform Parity:** Experience the exact same fixed layout, custom mappings, and performance across Windows, macOS, and Linux.
* **Pixel-Perfect Unicode & Legacy Support:** Flawless text rendering optimized for modern web typing, database entries, and legacy publishing workflows.
* **Blazing Fast Native Performance:** Built natively for each operating system to minimize input latency and resource footprints.
